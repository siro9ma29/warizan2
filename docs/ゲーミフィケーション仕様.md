## 4. つみあげ
### 4-1. ★・道具・はんこ（v1から）
- 5問中 5問＝★★★、4問＝★★、3問＝★、2問以下＝だっしゅつ できない（せいかいの数え方は今までどおり、まちがい1回までは せいかい）
- はじめて だっしゅつした へやで からくり道具
- 名人の はんこ：5問とも まちがい0・スキップなし・（Ⅰは）ヒントボタンなし
- すべての へやを だっしゅつ → やかたから だっしゅつ（看板が金色に光る）。Ⅰは レベル6 と 6（0をたてる）の どちらか一方でよい

### 4-2. とびらの累計と段位（毎回かならず増える）

- 段位：🔰みならい(0) → 🥉しょだん(10) → 🥈にだん(30) → 🥇さんだん(60) → ⚙️からくりし(100) → 🏯めいこう(160) → 👑でんせつの からくりし(250)

## 7. 実装メモ
- 共通の CSS／JS（`KK` モジュール）を両方のファイルに入れ、違いは `window.KK_CFG`（へや・道具・からくり・断面図の座標・だっしゅつ条件）
- 断面図は もとのレベルカードを かくして上に重ねたもの。へやを タッチすると もとのカードを クリックする（Ⅰのチャレンジの 解法えらびも そのまま）
- 文字の大きさは 断面図の幅（cqw）に合わせて変わる
- てじゅんの回数は advanceStep のたびに 直前の手順の種類を数える（しょうの 0／× は getExpectedDigits で判定）
- テスト：自動で問題をとくスクリプトで、ノーミス／まちがい・スキップあり／最後の へや→やかた だっしゅつ／「つぎの へや」を Ⅰ・Ⅱで確認。からくり8種の動き、からくり帳・かもん画面、1280×800・1024×600・たて向き・スマホ幅の表示を確認
